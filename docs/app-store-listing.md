## English (U.S.)

- Name: `LightView Image Viewer`
- Subtitle: `Fast, lightweight Mac viewing`
- Promotional text: `Free, lightweight, high-performance, ad-free, and open source. Browse image folders, open WebP, HEIC and SVG, and inspect EXIF locally.`

Description:

LightView is a free, lightweight, open-source Mac image viewer built for responsive folder browsing. Open a picture from Finder and move through the folder with the arrow keys. No ads, accounts, tracking, or uploads.

• Zoom, pan, rotate, flip, or switch to full screen with the toolbar or keyboard.
• Check dimensions and file size in the title bar. Press E for an EXIF overlay when metadata is available, or Command-I for full image information.
• Open JPEG, PNG, WebP, HEIC, SVG and more. AVIF is available on compatible macOS versions.
• Play animated GIF, APNG, and WebP, or run a folder slideshow.
